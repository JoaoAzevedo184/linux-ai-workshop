linux-cheat-sheet

comandos favoritos para consulta rápida

Navegação

  • pwdmostra o diretório atual
  • cd -volta ao diretório anterior
  • ls -lahlista detalhada com tamanhos legíveis
  • treeárvore de diretórios
  • find . -name "*.sh"busca arquivos por padrão

Arquivos

  • cp -r a bcopia recursivamente
  • mv a bmove ou renomeia
  • rm -rf dirremove pasta (cuidado!)
  • cat arqmostra o conteúdo
  • less arqvisualiza paginado

Permissões

  • chmod +x s.shtorna executável
  • chmod 644 arqrw para dono, r para o resto
  • chown user arqmuda o dono
  • stat arqdetalhes do arquivo
  • umaskmáscara de permissões padrão

Processos

  • htopmonitor interativo
  • ps auxlista todos os processos
  • kill -9 PIDforça encerramento
  • jobstarefas em background
  • nohup cmd &roda imune ao logout

Sistema

  • df -huso de disco
  • free -huso de memória
  • uname -ainfo do kernel/SO
  • uptimetempo ligado e carga
  • journalctl -xelogs do sistema

Pacotes (apt)

  • apt updateatualiza a lista
  • apt upgradeaplica atualizações
  • apt install xinstala pacote
  • apt search xbusca pacote
  • apt autoremoveremove órfãos

Rede

  • ip ainterfaces e IPs
  • ss -tulanpportas em uso
  • ping hosttesta conectividade
  • curl -I urlcabeçalhos HTTP
  • ssh user@hostconexão remota

Git

  • git statusestado do repo
  • git add .adiciona tudo ao stage
  • git commit -mcommit com mensagem
  • git pushenvia commits
  • git log --onelinehistórico resumido
